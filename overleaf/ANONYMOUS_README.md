# Q-OPS anonymous supplementary artifact

This package contains the double-blind NeurIPS 2026 workshop manuscript, appendices, frozen machine-readable evidence, reproducible figure/table generators, editable vector masters, and the original eight-asset technical clip-art family.

Build with `make`. The fail-closed staged build generates and decodes the clip-art package before composing any diagram, audits every cited reference against the dated primary-source registry, exports the three SVG figure masters with Inkscape, and compiles the paper. Run `make release-audit` for the complete numerical, reference, visual, structural, anonymity, and page-budget gate; run `make package` to reproduce the deterministic upload ZIP. The frozen computational implementation is supplied separately through the anonymous review artifact; identifying repository coordinates and commits are intentionally absent here.

The scientific claim is limited to exact shared-field reproduction and conditional statevector-level algorithmic evidence. This package does not claim byte-identical CSV reproduction, QPU performance, wall-clock or scaling advantage, universal benefit, workplace safety, fairness, welfare, or application-level quantum advantage.
