# Q-OPS anonymous supplementary artifact

This package contains the double-blind NeurIPS 2026 workshop manuscript, appendices, frozen machine-readable evidence, reproducible figure/table generators, editable vector masters, and the original seven-asset technical clip-art family.

Build with `make`. Regenerate release assets with `python3 scripts/generate_release_assets.py`, export the three SVG figure masters to PDF with Inkscape, and run `make visual-audit` before compiling. The frozen computational implementation is supplied separately through the anonymous review artifact; identifying repository coordinates and commits are intentionally absent here.

The scientific claim is limited to exact shared-field reproduction and conditional statevector-level algorithmic evidence. This package does not claim byte-identical CSV reproduction, QPU performance, wall-clock or scaling advantage, universal benefit, workplace safety, fairness, welfare, or application-level quantum advantage.
